# Brume vs Vercel: research notes

Checked: 2026-11-01. Official sources only: vercel.com, nextjs.org, github.com/vercel. "not found" means no official source confirmed it.

**What it is:** Vercel is a closed-source managed cloud. It is built for frontend and full-stack frameworks, Next.js first. Code runs as serverless Functions on Fluid compute, mostly on AWS, behind a global CDN. Containers and background workers ("Daemons") were added in beta in 2026.

## Where it is better than a self-hosted single-server alpha

1. **Global reach and resilience.** 126 PoPs and 19 compute regions, with automatic CDN rerouting when a region fails (function failover on Enterprise). One VPS behind a Cloudflare Tunnel is one machine in one place.
2. **Elastic scale with no ops.** Functions scale to 30,000 concurrency on Hobby and Pro and to zero when idle, billed on active CPU. A single Brume server has a fixed ceiling, and you size and patch it yourself.
3. **Security and compliance you inherit.** SOC 2 Type 2, ISO 27001:2022, PCI DSS attestations, a HIPAA BAA add-on, plus free automatic DDoS mitigation and a WAF on every plan. Brume 0.1 has no audits or certifications, and the operator owns host hardening.
4. **Framework-native frontend features.** Preview URL per pull request, instant rollback, rolling releases, Skew Protection, ISR, image optimization and Next.js integration from the team that maintains Next.js.
5. **Mature agent tooling.** A hosted OAuth MCP server that works with many reviewed clients, an agent-aware CLI, skills and llms.txt, and Firecracker sandboxes for running agent-generated code safely.

## Suggested verdict

Pick Vercel for global, autoscaling frontends and Next.js apps with compliance handled for you, and accept usage-based bills and Vercel-held data. Pick Brume when you want containers, databases and backups on one server and one S3 bucket that you own, at a fixed VPS cost.
