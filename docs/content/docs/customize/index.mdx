Brume's source code is available under the [Functional Source License](/docs/customize/development#license) (FSL-1.1-ALv2). You can read every line that runs on your server, build it yourself and change it. This section is for people who want to go past using Brume.

## What you can do

- **Build Brume from source** instead of installing the published binaries.
- **Sign your own builds** with your own minisign key: a server accepts as updates only binaries signed with one of the two keys embedded in the binary it runs.
- **Change the code:** the Rust services, or the React panel.
- **Improve these docs,** by hand or with a coding agent.

## How the code is organized

Brume is written in Rust (tokio, clap) with a React panel (TanStack Query, Router and DB, coss ui, Tailwind, React Flow). One binary, `brume`, has a subcommand for each service. The engine and the agent keep their decision logic in cores that do no I/O, so the whole of Brume can run in a deterministic simulation. The panel is compiled in CI and embedded in the signed binary: the server never runs npm.

  The first milestone of alpha 0.1 runs on your own machine: see [Run Brume locally](/docs/customize/run-locally). The rest of alpha 0.1, such as the installer, update signing and the CI checks, is still design.
</Callout>
