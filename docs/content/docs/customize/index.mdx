Brume is open source. You can read every line that runs on your server, build it yourself and change it. This section is for people who want to go past using Brume.

## What you can do

- **Build Brume from source** instead of installing the published binaries.
- **Sign your own releases** with your own key, so your servers only accept your builds.
- **Change the code:** the Rust engine and API, or the React panel.
- **Improve these docs,** by hand or with a coding agent.

## How the code is organized

Brume is written in Rust (tokio, clap) with a React panel (TanStack, shadcn, Tailwind). The panel is compiled in CI and embedded in the signed binary: the server never runs npm.
